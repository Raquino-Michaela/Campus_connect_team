## Project Overview
Campus Connect is a web-based campus event finder project designed to help students, faculty, and organizations discover, organize, and manage events within their school community. Our goal is to make it easier for everyone to stay updated on school activities and never miss important campus events.

## Features
- **Event Discovery** – Browse upcoming campus events and activities.
- **Event Registration** – Register for events online.
- **Ticket Management** – View and manage registered event tickets.
- **Event Management** – Allow organizers to create and manage events.
- **Event Updates** – Receive information about upcoming events.
  
## How to Use
1. Open the PTC Event Hub website.
2. Log in using your student account.
3. Browse the available campus events.
4. Select an event to view its details, date, time, and venue.
5. Click the Register button to join your chosen event.
6. Wait for the registration confirmation.
7. Go to My Tickets to view your registered events.
8. Attend the event on the scheduled date and time.
